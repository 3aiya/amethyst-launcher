# Security Policy

## Supported versions

Only the [latest release](https://github.com/3aiya/amethyst-launcher/releases/latest)
receives security fixes. The launcher updates itself automatically, so please make
sure you are on the newest version before reporting.

## Reporting a vulnerability

Please **do not** report security issues in public GitHub issues.

Instead, use GitHub's
[private vulnerability reporting](https://github.com/3aiya/amethyst-launcher/security/advisories/new)
and include:

- a description of the issue and its impact,
- steps to reproduce or a proof of concept,
- the launcher version you tested.

You can expect an initial response within a few days. Once the issue is fixed, a
new release will be published and you will be credited in the release notes if
you wish.
